这个博客从 2012 年写到现在，中间换过一次皮，然后那层皮一穿就是快十年。

白底黑字，干净是干净，就是放到 2026 年看，怎么说呢，像把去年的对联又贴了一年——没什么不对，就是该换了。

这回改版的原则只有一条：**内容一个字不动，样式全换**。40 篇文章、图片、关于页、RSS，原样保留；动的是长相。

## 改了什么

**首页**

以前是“标题 + 一列文章”，现在是：顶部一句简介，右边三张文章封面叠成的拼贴；最新一篇置顶成双栏主视觉；下面每页 16 篇卡片网格，每张都带封面图。

**文章页**

封面图做成顶部横幅，标题直接压在图上；正文收窄到合适的行宽，行高放到 1.9，读长文舒服一些；有目录的文章右侧自动生成目录，滚动时高亮；底部上一篇 / 下一篇做成卡片。

**归档页**

按年份分组，顶部标签云，点标签实时筛选，筛选结果会带进链接里，可以直接分享给别人。

**关于页**

终于统一风格了。以前是个独立的暗色页面，跟博客完全是两家人；现在改回“模板 + 一个 md 文件”的结构，文案还是那碗丸子汤。

**其他**

深浅色主题，右上角一键切换，默认跟随系统；阅读进度条；PWA 离线缓存；样式带版本号，以后更新不会再被浏览器缓存坑到。

## 几句技术话

- 还是 Jekyll + GitHub Pages，没换技术栈
- 老版本在本地留了完整备份（含 git 历史），随时能回滚
- 写文章的方式完全没变：Markdown 丢进 `_posts/`，推上去，首页、归档、RSS 自动更新

## 隔天，又加了个分类

改版第二天，补上了一个想了很久的功能：**文章分类**。

以前只有标签——标签是随手贴的，多而杂；现在每篇文章归进一个分类，单层、不嵌套，和标签共存。42 篇文章全部分好了，一共 6 个分类：

| 分类 | 篇数 |
| --- | --- |
| 随笔 | 17 |
| 年终总结 | 10 |
| 科技与AI | 7 |
| 丸子桌面 | 4 |
| 工作与产品 | 2 |
| 博客 | 2 |

首页统计行下面多了一条分类栏，6 个分类一行排开，点一下直达归档页里对应的分类：

![首页分类栏](/img/2026-ui/category-strip.jpg)

归档页侧栏也加了「分类筛选」，和标签筛选可以叠加用——先选分类再选标签，结果实时过滤，链接照样能分享：

![归档页分类筛选](/img/2026-ui/archive-category.jpg)

文章页顶部和文末会显示这篇的分类。有个细节值得说：分类只用于展示和筛选，**不拼进网址**，老文章的链接一个都没变。

改版这事，拖了几年，终于动手了。希望这身新衣服，能穿得比上一身久一点。
